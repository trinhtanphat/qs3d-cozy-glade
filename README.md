## 📖 Overview

**Tiny Glade (Browser Edition)** is a relaxing, gridless 3D medieval castle and meadow diorama sandbox that runs entirely inside a single browser tab — **zero backend, zero external texture/model/audio downloads, and runnable directly via `file://` double-click**.

Draw a curved stone wall across rolling hills and watch staggered limestone courses lay themselves stone by stone with marimba-like tactile foley. Paint a cobblestone lane through that wall and it **automatically carves a walkable 3D stone voussoir archway** complete with radial wedge blocks, a proud keystone, jamb piers, and airtight tapered spandrels. Sweep a path across a sculpted pond or winding brook and an **arched stone-and-timber bridge** rises over depth-absorbed Beer-Lambert water rimmed with shoreline foam, water lilies, cattails, and rippling swans.

All visual and acoustic assets are synthesized mathematically in JavaScript and GLSL ES 3.0 at startup — packing the entire game engine, `three@0.170.0`, shaders, 4 curated starter dioramas, and UI into a single portable **`929.6 KB` (`tiny-glade-aaa.html`)** file.

### Option 1: 🌐 1-Click Live Demo (Instant · Zero Install)
Play immediately in any modern desktop or mobile browser (Chrome, Edge, Safari, Firefox with WebGL2):

👉 **[https://cdn.firetable.tech/file/tiny-glade-aaa.html](https://cdn.firetable.tech/file/tiny-glade-aaa.html)**

### Option 2: 📄 Zero-Server Local HTML (`file://` Double-Click)
Both `tiny-glade-aaa.html` (100% self-contained single file, `929.6 KB`) and `index.html` + `dist/` are pre-built and committed to this repository — **no Node.js or local HTTP server required**:

```bash
git clone https://github.com/FireTable/tiny-glade.git
cd tiny-glade

# macOS: open the standalone single-file HTML directly
open tiny-glade-aaa.html
# (or double-click tiny-glade-aaa.html / index.html in Finder / Windows Explorer)
```

### Option 3: 🛠️ Modular ES Source Build & Local Preview
To modify the modular ES2022 source under `src/` and rebuild both `dist/` and `tiny-glade-aaa.html` (~70 ms via `esbuild`):

```bash
# 1. Install dependencies (three@0.170.0 + esbuild)
npm install

# 2. Rebuild dist/glade.js, dist/glade.css, and standalone tiny-glade-aaa.html
npm run build

# 3. (Optional) Serve over local HTTP at http://localhost:8080
npm run preview
```

## ✨ Key Features

### 🔮 WebGL2 HDR Rendering & Post-Processing Pipeline (`src/engine/`)
* **HalfFloat MSAA HDR & Filmic AgX Tone Mapping**: Full high-dynamic-range `HalfFloatType` multisampled render pipeline with custom AgX-inspired tone mapping that preserves crisp sunlit limestone highlights and warm night-time lantern glow without color clipping.
* **Physical Rayleigh + Mie Sky & 24h Celestial Cycle**: Continuous `00:00–24:00` sky dome shader with atmospheric scattering, sun disc, cratered lunar disc with a non-blooming corona, twinkling starfield, and animated multi-octave FBM cumulus clouds tinted by dawn and golden-hour light.
* **Throttled Dynamic PMREM IBL & Stabilized Shadows**: `PMREMGenerator` environment lighting (`scene.environment`) updates smoothly from the live sky shader without frame drops; directional sun shadows (`4096²` Ultra / `2048²` High / `1024²` Balanced `PCFSoftShadowMap`) use texel-grid snapping to eliminate shadow shimmer while orbiting.
* **Screen-Space GTAO, Volumetric Mist & Tilt-Shift DoF**: Ground-Truth Ambient Occlusion grounds every stone course and roof eave with zero sky haloing, paired with sun shafts, valley mist, selective HDR bloom, and autofocus miniature **Tilt-Shift Depth of Field**.
* **Depth-Aware Beer-Lambert Water (`WaterSystem.js`)**: Samples a live `256×256` `HalfFloatType` terrain height texture for crystal shallow-to-emerald deep absorption, animated shoreline foam, Fresnel sky reflections, solar/lunar glints, and interactive water ripples from paddling swans and cursor strokes.
* **100% Procedural PBR Material Synthesizer (`MaterialLibrary.js`)**: Generates `512×512` mipmapped albedo, Worley/FBM normal, roughness, and AO maps on startup — including limestone, Cotswold stone, granite, Tudor plaster, 5 roof shingle palettes, timber, cobblestone, sun-backlit subsurface foliage, and day-to-candlelit interior parallax windows.

### 🏰 Reactive Brick-by-Brick Procedural Architecture (`src/arch/`)
* **Coursed Beveled Masonry & Sloped Plinth Foundations**: Walls, cottages, and towers are assembled from individual 3D beveled stones with per-block color jitter, recessed dark-mortar cores, and battered stone foundations that extend seamlessly down steep hillsides and pond banks with zero floating gaps.
* **Signature Auto-Carved 3D Voussoir Archways (`WallBuilder.js`)**: Drawing any cobblestone or country dirt path across a straight, curved, sloped, or crenellated Catmull-Rom stone wall automatically carves a walkable portal framed by radial 3D stone voussoirs, a proud keystone, flanking jamb piers, and binary-searched tapered spandrel wedges.
* **Auto-Generated Arched Water Bridges (`BridgeAndClutter.js`)**: Painting a path across any pond or brook automatically constructs an arched cobblestone bridge with stone end-piers and curved timber railings.
* **Compound Cottages & Cylindrical Castle Keeps (`BuildingBuilder.js`)**: Place rectangular cottages/halls (stone or half-timbered Tudor upper floors, gable dormers) and round towers (conical "witch-hat" flared shingle roofs or crenellated battlements) that merge cleanly into multi-wing keeps.

### 🌿 Lush Living Meadow, Seasons & Wildlife (`src/world/`)
* **Up to 195,000 GPU Wind-Swept Grass Blades (`FoliageSystem.js`)**: 3-blade curved grass tufts animated on the GPU with rolling wind gusts, sun-tip translucency, seasonal palettes (**Summer**, **Autumn**, **Spring**), and real-time exclusion masks under building footprints, cobblestone paths, and ponds.
* **Studio Ghibli Puff Trees, Wildflowers & Aquatic Flora**: Multi-canopy broadleaf puff trees and conifers with subsurface scattering, meadow wildflower clusters (scarlet poppies, buttercups, lavender, daisies), shoreline cattails, and floating pond lilies.
* **Interactive Sheep, Rippling Swans & Particles (`WildlifeAndParticles.js`)**: Grazing fluffy sheep wander the glade (**click any sheep in Select mode to pet it** — triggering a joyful hop, floating pink hearts, and a cute bleat!), swans glide across ponds leaving real-time ring ripples, butterflies flutter by day, golden fireflies drift at dusk/night, and cozy smoke puffs rise from cottage chimneys.

### 🎛️ Tactile 3D Gizmos, Stroll Mode & Procedural WebAudio (`src/game/` & `src/ux/`)
* **In-World 3D Manipulation Handles**: Click any building or wall to pull intuitive 3D handles directly in world space — wall height, roof pitch & witch-hat curve, footprint width/depth/radius, yaw rotation, and live roof/wall material swatches.
* **First-Person Tiny Stroll Mode (`F`)**: Transition smoothly from miniature orbit camera down to `1.65 m` eye height to stroll along winding paths, cross arched pond bridges, and walk straight under your own stone courtyard archways.
* **100% Procedural WebAudio Foley & Soundtrack (`AudioEngine.js`)**: Synthesizes wooden/stone marimba brick-pop clacks pitched progressively along wall/path strokes, roof shingle snaps, water splashes, sheep formant bleats, wind-scaled breeze noise, daytime birdsong, evening crickets, and sparse medieval pentatonic harp/lute plucks.
* **40-Step Undo/Redo, JSON Export/Import, 4 Starter Presets & Photo Mode (`P`)**: Switch instantly between *Lakeside Keep*, *Cotswold Brook Hamlet*, *Starlit Castle Ruins*, and *Fresh Meadow*, export/import full world JSON files, or press `P` for HUD-free high-res PNG capture.

## 🛠️ Tech Stack

| Layer | Technology | Description |
| :--- | :--- | :--- |
| **3D Engine** | [Three.js `0.170.0`](https://threejs.org) (`WebGL2`) | `HalfFloatType` MSAA HDR pipeline, `InstancedMesh` masonry &amp; foliage, custom `onBeforeCompile` triplanar PBR shaders |
| **Atmosphere & Water** | Custom GLSL ES 3.0 Shaders | Rayleigh/Mie sky dome + FBM clouds + dynamic `PMREMGenerator` IBL + Beer-Lambert depth water with shoreline foam &amp; ripples |
| **Post-Processing** | Custom Fullscreen Pass Stack (`PostFX.js`) | Screen-space GTAO + Volumetric Sun Shafts &amp; Valley Mist + HDR Emissive Bloom + Autofocus Miniature Tilt-Shift DoF + AgX Tone Mapping |
| **Procedural Geometry** | Vanilla ES2022 (`src/arch/`) | Beveled ashlar courses, Catmull-Rom walls, auto-carved 3D radial voussoir archways, tapered spandrels &amp; arched pond bridges |
| **Audio Synthesizer** | Native `Web Audio API` (`AudioEngine.js`) | 100% procedural marimba brick-pop foley, wind-filtered breeze, birds/crickets, sheep formant bleats &amp; pentatonic harp/lute |
| **Bundler** | [esbuild](https://esbuild.github.io) (`build.mjs`) | Compiles modular ES2022 into both `dist/glade.js` and the standalone `929.6 KB` single-file `tiny-glade-aaa.html` in ~70 ms |
